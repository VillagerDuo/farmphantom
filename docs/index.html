Farming engine · our priorities

Odak noktası Focus

Motoru baştan yazmak değil; mevcut idle, kuyruk ve takip akışını adım adım iyileştirmek.

Not a rewrite: steadily improve the existing idling, queue, and tracking flows.

  • GüvenilirlikReliabilityGeçici hatalarda daha iyi toparlanma ve anlaşılır hata durumu.Better recovery from transient errors and clearer failure status.
  • KuyrukQueueParalel oyun sınırını ve seçilen oyun sırasını daha öngörülebilir yönetme.More predictable handling of parallel limits and chosen game order.
  • Düşüş takibiDrop trackingEnvanter değişimiyle rozet ilerlemesini daha tutarlı eşleştirme.Reconcile inventory changes with badge progress more consistently.
  • PerformansPerformanceGereksiz bekleme ve sorguları azaltırken takibi duyarlı tutma.Reduce unnecessary waits and polling while keeping tracking responsive.
  • İlk kullanımFirst runSteam, DLL ve oturum gereksinimlerini daha net anlatan başlangıç akışı.A clearer setup flow for Steam, the native DLL, and sign-in requirements.

Çalıştırmak

Run it

Hazır Windows sürümünü kurma

Install a ready-to-run Windows build

GitHub Releases sayfasından Setup veya portable ZIP’i indir.

Download Setup or the portable ZIP from GitHub Releases.

Setup: Setup EXE’yi çalıştır ve sihirbazı tamamla. .NET 10 ayrıca gerekmez. İlk açılışta resmi steam_api64.dll dosyasını seç; FarmPhantom dosyayı uygulamanın yanına kopyalar. İstemi kapatırsan Ayarlar → Steamworks bölümünden seçebilirsin.

Setup: Run the Setup exe and complete the wizard. No separate .NET 10 install is needed. On first launch, select the official steam_api64.dll; FarmPhantom copies it beside the app. If you dismiss the prompt, select it later in Settings → Steamworks.

Portable: ZIP’in tamamını yazma iznin olan bir klasöre çıkar ve içindeki FarmPhantom.exe dosyasını çalıştır. DLL’i önceden exe’nin yanına koyabilir veya ilk açılışta seçebilirsin.

Portable: Extract the entire ZIP to a writable folder and run FarmPhantom.exe. Put the DLL beside the exe beforehand or select it on first launch.

İki sürümde de Steam kurulu ve açık olmalı. DLL varsayılan paketlere dahil değildir; resmi kaynaklar aşağıda. Steam çerezlerini paylaşma.

Both versions require Steam to be installed and running. The DLL is not included by default; official sources are below. Never share your Steam cookies.

Kaynak kodundan çalıştırma

Run from source

  1. .NET 10 SDK kur.
  2. Install the .NET 10 SDK.
  3. cd app → dotnet run

steam_api64.dll dosyasını edinme

Get steam_api64.dll

1. Resmi Steamworks.NET 2024.8.0 Standalone ZIP’ini indir. Bu sürüm uygulamanın kullandığı Steamworks.NET paketiyle eşleşir.

1. Download the official Steamworks.NET 2024.8.0 Standalone ZIP. It matches the Steamworks.NET version used by this app.

2. ZIP’ten Windows-x64/steam_api64.dll dosyasını çıkarıp app/ klasörüne kopyala. Kendin yayımlıyorsan DLL’i exe’nin yanında tut.

2. Extract Windows-x64/steam_api64.dll and copy it into app/. For your own publish, keep the DLL beside the exe.

Alternatif: Valve Steamworks SDK’yı indir (Steamworks partner hesabı gerekir) ve sdk/redistributable_bin/win64/steam_api64.dll dosyasını kullan.

Alternative: get the Valve Steamworks SDK (requires a Steamworks partner account) and use sdk/redistributable_bin/win64/steam_api64.dll.

DLL depoda veya varsayılan kurulumda yoktur. Başka bir oyundan ya da DLL indirme sitesinden alma; yeniden dağıtmadan önce Valve’ın Steamworks şartlarını kontrol et.

The DLL is not in this repository or the default installer. Don’t copy it from another game or a DLL-download site; check Valve’s Steamworks terms before redistributing it.

Giriş Steam çerezleriyle. sessionid ve steamLoginSecure hesap anahtarı gibi; paylaşma. Idle Steam kurallarına takılabilir, yüksek paralel sayı riski artırır.

Login is Steam cookies. sessionid and steamLoginSecure are full account access; don’t share them. Idle can still get an account restricted. High parallel counts make that more likely.
